# Шежіре жобасы

Қазақ ру-тайпаларының интерактивті этникалық шежіресі: сақ, үйсін, ғұн, қаңлы, динлин мен дайлардан бастап түркі, оғыз, қыпшақ, моңғол дәуірлері арқылы Алаш пен үш жүзге дейінгі жол. Жүзден тыс топтар (төре, қожа, төлеңгіт) да көрсетілген.

Ашу: `index.html` файлын браузерде ашыңыз немесе GitHub Pages арқылы жариялаңыз (Settings → Pages → Branch: main, / root).

## Не бар
- Төрт деңгейлі ағаш: Ежелгі дәуір → Түркі дәуірі → Моңғол дәуірі → жүздер мен тайпалар. Тайпаны басқанда шығу тегі тізбегі жанады.
- Әр тайпа: ұраны, негізгі рулары, Омарбеков бойынша шығу тегі, Y-ДНҚ бойынша басым гаплотоп.
- Шежіре мен генетиканы салыстыратын кесте, бес даулы сұрақ, сабаққа арналған тапсырмалар.

## Ескертулер
1. Шығу тегі тізбектері негізінен Т. Омарбековтың екі оқу құралына сүйенеді; кейбірі даулы (Алшын ← Ашина, Адай ← дайлар, Керей ← Сарыүйсін).
2. Шежіре мен генетика кейде қайшы келеді: үйсін руларының ортақ атасы шамамен 700–800 жыл бұрын өмір сүрген; Керейдің Сарыүйсіннен, қожалардың арабтан тарағаны генетикамен расталмады; Әлімұлы мен Байұлының ортақ атасы расталды.
3. Y-ДНҚ тек әке жағын көрсетеді; гаплотоп этносқа тең емес; генетикалық жас есептеулерінің қателігі ±200 жылдай.
4. Кейбір іріктемелер шағын: Уақ (n=45), Төре (n=28); төлеңгіттер бойынша жүйелі зерттеу табылмады.
5. Арғын, Найман, Керей, Уақ, Қыпшақ, Қоңырат, Кіші жүз және Төре пайыздары Wikipedia жиынтық кестесінен алынды; кестенің бағандары ығысқан, ретін бастапқы зерттеулер бойынша анықтадым. Түпнұсқамен тексеру ұсынылады.
6. Ұрандар мен рулар дереккөзге қарай өзгереді.
